# TW-SCH-004 -- MTCH2120 Capacitive Touch

## Objective

Implement the hidden capacitive keypad.

### Interfaces

-   I²C to ESP32-C6
-   Interrupt/output pin
-   3.3 V supply

### Requirements

-   Moisture tolerant layout
-   Guard/shield support
-   Bottom-side touch electrodes
-   Decoupling at IC

### Deliverables

-   MTCH2120
-   I²C pull-ups
-   Touch connector/electrodes
