# TW-SCH-003 -- HLK-ZW101 Fingerprint Interface

## Objective

Integrate the Hi-Link HLK-ZW101 fingerprint module.

### Interfaces

-   UART to ESP32-C6
-   3.3 V supply
-   Reset/Wake (if used)

### Design Requirements

-   ESD protection near connector
-   FPC/board connector
-   Short UART routing
-   Test pads for TX/RX

### Deliverables

-   Connector
-   Power filtering
-   Net labels
-   ERC-clean schematic
