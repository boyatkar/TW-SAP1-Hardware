# TW-TEST-001 -- Engineering Validation Test (EVT) Plan

**Project:** TW-SAP1 Hardware Platform **Product:** XS3400 Residential
Smart Lock **Revision:** A (Draft)

## Objectives

Verify that the first prototype satisfies functional, electrical and
mechanical requirements.

## EVT Checklist

### Power

-   Battery operation
-   USB-C emergency power
-   Standby current
-   Brownout recovery

### Wireless

-   Wi-Fi
-   BLE
-   RF range

### Authentication

-   Fingerprint enrollment & unlock
-   PIN entry
-   XSOS app unlock
-   Mechanical key override

### Motor

-   Lock/unlock operation
-   Stall protection
-   Current measurement

### Touch

-   Sensitivity
-   Wet finger behaviour
-   False touch immunity

### Reliability

-   Thermal cycling
-   Battery endurance
-   Basic ingress checks
-   Mechanical endurance integration testing

## Deliverables

-   Test report
-   Bug list
-   BOM updates
-   Revision recommendations
